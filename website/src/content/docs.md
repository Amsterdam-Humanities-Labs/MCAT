MCAT is a desktop app for tracking how content-moderation status changes over time.

## Installation

Download the latest build for your platform and run it — there is no installer.

### Linux

Grab the AppImage, mark it executable, and launch it.

### macOS

Open the notarized app bundle and drag it to Applications.

## Your first project

Create a project, paste in the URLs you want to watch, and start tracking.

## Screenshots

Every check captures a screenshot — that visual record is the core of the tool.
